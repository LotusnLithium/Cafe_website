# 🎭 Break a Leg Cafe — Palghar

Official modern web application for **Break a Leg Cafe**, Palghar's premier spotlight bistro and artisanal momo destination located at:
> **Shop No. 8, Sai Ashish Apartment, Mahim Road (West), Kuldeep Nagar, Palghar, Maharashtra 401404**

📍 **Google Maps**: [https://share.google/MZPWZAXG6zlNC4sWi](https://share.google/MZPWZAXG6zlNC4sWi)

---

## ✨ Features

- 🎭 **Theatrical Spotlight Aesthetics**: Obsidian espresso theme with glowing neon amber and theatre crimson accents.
- 🥟 **Interactive Digital Menu**: Curated categories (Signature Momos, Gourmet Smash Burgers, Grilled Sandwiches, Loaded Fries, Wok Fusion, Shakes & Desserts).
- 💬 **1-Click WhatsApp Ordering**: Formats full itemized order receipts directly to the cafe's WhatsApp number with zero commissions.
- 🎪 **VIP Table & Backstage Booking**: Online table reservation with custom seating zones (Spotlight Booth, Cozy Couple Corner, Backstage Lounge).
- 📍 **Palghar Delivery Coverage**: Delivery zone tracking and Google Maps integration.
- ⭐ **Google & Justdial Reviews**: 4.8/5 rating breakdown with verified customer testimonials.
- 🛡️ **Cafe Owner Live Desk**: Admin preview for real-time order stream, table bookings log, and live menu stock toggling.
- 📱 **Floating Action Dock**: Instant access to Menu, Table Booking, WhatsApp, and Cart counter.

---

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite
- **Icons**: Lucide React
- **Animations**: Canvas Confetti, CSS Custom Properties & Glassmorphism
- **Audio**: Web Audio API Sound Synthesizer

## 🚀 Getting Started

```bash
# 1. Clone the repository
git clone https://github.com/LotusnLithium/Cafe_website.git

# 2. Navigate to project
cd Cafe_website

# 3. Install dependencies
npm install

# 4. Start development server
npm run dev

# 5. Build production bundle
npm run build
```
